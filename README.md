# python-dsa
A personal reference library for Data Structures and Algorithms (DSA) implemented in Python. 

## 🎯 Purpose
* To keep a clean, dedicated space for computer science fundamentals, separate from everyday scripting. 
* This is used to track algorithmic problem-solving progress and serves as a quick reference for optimal code design.

## 🗂️ Directory Structure

* **`/data_structures`**
* **`/algorithms`**

## 📝 Notes
Reserved for logging specific algorithms for future review or linking to useful visualization tools.
