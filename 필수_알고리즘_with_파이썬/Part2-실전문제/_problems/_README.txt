## 교재
파이썬과 함께 하는 자료구조의 이해, 양성봉 지음

## Recursion의 번역
교재에서 재귀 호출(recursive call)이라는 표현을 쓰고 있지만, 순환 (recursion)으로 변경합니다.
* 이유: 함수의 순환이 함수의 재귀보다 더 직관적으로 이해하기 쉬운 표현입니다.

Function recursion, Recursion, Recursive call은 동일한 프로그래밍 테크닉을 지칭합니다.
한국어 번역이 통일되지 않고, 다양한 표현을 가집니다.
* recursion: 순환, 재귀
* recursive call: 재귀 호출
* function recursion: 함수 순환, 함수 재귀
